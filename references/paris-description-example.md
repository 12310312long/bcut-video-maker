# 《巴黎解放演说》简介开篇（用户确认稿）

1944年8月25日傍晚，戴高乐来到巴黎市政厅。巴黎解放委员会和全国抵抗委员会的代表已经在这里等他。过去几天，城里一直在打仗。19日清晨，参加起义的巴黎警察占领了塞纳河畔的警察总局，抵抗组织在各区筑起街垒。24日夜里，勒克莱尔将军麾下的先头部队抵达市政厅。第二天，法军第2装甲师主力和美军第4步兵师陆续进入市区，德军巴黎守备司令签署投降书。戴高乐进城以后，先去了陆军部，又去警察总局看望参加起义的警察。等他赶到市政厅，已是晚上七点左右。

戴高乐开口便说，在自己的家园，在这座为解放自己而奋起的巴黎，谁也不必掩饰心里的激动。他接连几次念出巴黎的名字，说起这座城四年间受过的凌辱和苦难。他把解放的功劳先归给巴黎人自己，随后讲到法国军队，以及在占领岁月里始终支持着首都的人们。「法国回到了巴黎，回到了自己的家。」在他口中，法国带着一身伤痕归来，眼下还有许多事要做。

讲到这里，戴高乐提起了仍在外地作战的法国士兵。曾在意大利打过仗的部队已经从法国南部登陆，正沿罗讷河谷向北推进；参加地下抵抗的人，也将编入正规军。他提醒在场的人，巴黎的德军已经投降，法国境内仍有大片土地处在占领之下。临近结尾，他谈起国家的团结。往后还要一起打仗，一起重建家园，他希望法国人能像兄弟姐妹一样相处。这就是巴黎解放当晚，戴高乐在市政厅里留给同胞的嘱托。
