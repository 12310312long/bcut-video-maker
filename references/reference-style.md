# 提取参考文案与改写表达风格

用户要求学习某条视频的文案或表达方式时使用。先锁定具体链接；只在“这个视频”等指代确实有多个候选时澄清，不重复确认已经给定的参考。

## 先取得实际文本

优先顺序：用户提供的文案或字幕 → 合法可访问的平台字幕 → 原音频自动转写。平台公开字幕不存在或不可访问时直接转写，不把反复抽帧读字幕当常规方案；抽帧只用于核查专名、数字、原声字幕和视觉节奏。无法取得实际内容时说明已读到的范围，不靠标题、简介或记忆声称分析了整条视频。

可使用已有转写 MCP/CLI；本地后备工具见 scripts/reference_text.py。对已取得的本地音频或视频执行：

```text
PYTHON -m pip install -r <skill>/scripts/requirements-asr.txt
PYTHON <skill>/scripts/reference_text.py <参考音频或视频> --output <研究目录/转写> --prompt "已知人物与专名"
```

支持 --start/--duration 抽取局部、--language auto 或语言码、--model、--threads、--cache-dir。默认 small 多语言模型、CPU int8；不依赖 CUDA。首次可能下载模型，缓存留在用户缓存目录，不打包进 skill 或成片交付。语音识别依赖为可选项，不强制所有视频安装。使用 FFmpeg 解码为 PCM，避免依赖 PyAV 的 metadata_errors 接口差异；这是本项目实际遇到并验证的兼容性问题。

输出带时序文本、SRT 和含词时间/置信信息的 JSON。时间均相对所选片段，原文件偏移记录在 source_start_seconds；与原片时间码对应时须相加。不要把这个 JSON 直接当 edge-tts WordBoundary。输入及输出保留在研究目录，避免覆盖用户已认可的字幕。

ASR 可能把银元、人名、书名等识别成同音字。对开头、关键机制、结尾和引文回看原字幕/资料；识别结果是表达分析的输入，不是史实证据。报告实际完成的方式与范围，不能把 ASR 抽核说成人工听音。记录耗时，不承诺每台电脑都能按同样速度转写。

## 提炼可迁移的写法

形成简短“参考表达说明”，记录参考链接与已读范围，提取以下有用维度：

- 开头怎样建立具体困难、利益关系或异常现象，以及多久接回主题。
- 人物何时出现，背景如何穿插，哪些信息用行动和物件交代。
- 句子长短、口语程度、衔接词、解释密度与自然停顿。
- 抽象机制如何拆开：先发生什么，为什么，接下来怎样变化。
- 采访和旁白怎样分工，结尾怎样回扣已经讲过的事实。

只采用适合当前题材的特征，不把博主的口头禅、夸张修辞、专有段落、第一人称经历或未经核查的数字搬进新片。文案写法、配音声线、画面节奏是不同层面；分析文字不能声称已完成声线分析，不因学习文案而自动更换或克隆配音。

## 用户V13定稿的叙事习惯

这是用户精心修改并要求长期学习的写法，历史课程片默认参照，同时学习结构和措辞。完整原文存于[上海V13用户定稿](examples/shanghai-v13-user-narration.md)，需要对照全篇节奏时阅读。原文按用户文件原样保存，不以本指南再次润色。它是表达样本，不是其他项目史实的通用来源；人物、数字、引语和细节用于新片前仍须独立核查。

开头先建立事件及其约束。样本在介绍上海战役时交代工厂、银行、码头和居民区靠得近，使观众先理解“保全市区”为什么难。背景应解释后面行动的取舍，不用百科式介绍拖延主线。之后用“上海是保下来了，可新生政权一接手，经济上的难题就压了过来”接住已经发生的结果，引出下一件事。

人物在问题需要他时出场。样本先讲抛售银元失败，到“光靠抛售，已经压不住了”才引出陈云；其学徒经历和东北财经工作直接解释他为什么能处理这个问题。不先写一长段生平，也不为了增强故事性编造人物心理、对白或关系。证券大楼的房间、电话和暗号等细节用来说明交易网络如何运转，不能把细节当装饰堆满每段。

机制要讲到人怎样行动、处境怎样变化。“市场上的货越少，老百姓越慌，越慌越抢”让观众理解涨价如何被推上去；“刚买进的纱布还没转手，市价已经掉下来了，借的钱却还要付利息”把囤货失败和资金压力放进同一个可理解的过程。不能只报政策名称、投放数量和最终胜利，省掉中间的市场反应。也要保留财政、发行、运输等已经有证据的多重原因。

判断紧跟事实，理论紧跟行动。先讲跑工厂、跑市场、改变原先疏散设想，再说“先看实情，再改办法，这就是从实际出发”。理论帮助观众命名刚看见的做法，不在每个段尾贴“体现了某某”的标签。史实上允许出现试错、退一步的打算和调整，不能把所有决定写成从一开始便胸有成竹。

结尾用生活变化回答前文的质疑。样本先回到米价、开工和市民买得起东西，再落下“马上得天下”和“马上治天下”的判断。收束要有前文铺垫，不能突然添新案例、空泛拔高或用口号替代已经展开的事实。学习其回扣方法，不要求每个主题都采用政治判断或同一句式。

## 措辞习惯同样是默认参考

重点学习词句在上下文里做了什么，不把以下词组当成必须出现的清单。保留叙述者的判断力和口语感，不加聊天口头禅来假装自然，也不为了“有劲”夸大史实。

| 写法 | 用户定稿中的例子 | 新文案怎样吸收 |
|---|---|---|
| 承接已发生的结果，再落到新困难 | “上海是保下来了，可……” | 让“可”连接真正的转折，避免每段重新宣布主题 |
| 顺势解释缘由 | “原来四月一日……” | 先给观众看见的现象，再补理解所需的规定或背景，不必人为插一道设问 |
| 给压力分出轻重 | “更要命的是，上海人已经苦旧纸币久矣” | 递进必须带来更难解决的新条件，不能只换一个形容词 |
| 用时间和动作写出反应 | “可银元刚露面，就被投机商一口吃进” | “刚……就……”承担实际先后和因果，不用机械反转制造戏剧性 |
| 用可看见的动词解释治理 | “跑工厂”“跑市场”“摸清楚”“一车车往上海调” | 写谁在做什么、货怎样移动、办法怎样落实，减少连续堆叠抽象名词 |
| 把统筹落到具体问题 | “上海缺什么，各地能拿出什么，铁路怎么接” | 用对象、数量关系和接续动作说明组织工作，不靠“统筹推进”一笔带过 |
| 用短判断给长事实落点 | “光靠抛售，已经压不住了” | 完整事实句之后可接短判断；不要把整篇切成碎句或每段凑一句金句 |
| 以生活动词呈现结果 | “米价稳了，工厂开了工，市民手里的钱又能买到东西” | 说清谁的生活或工作发生什么变化，再作必要总结 |

句子以完整口语为主，长短相间。解释背景、行动条件和机制时允许长句，转折、判断和结果处收短；不用全篇等长排比，也不把每句都写成“某某了”。“可”“原来”“所以”“与此同时”“两天后”等词要有可追溯的逻辑或时间对象，不能仅为顺口而掩盖年代跳跃。

偏好“压不住”“撑不住”“接上”“算账”“攥在手里”“派上用场”这类有对象、有动作结果的说法。合适时可以使用“钱袋子”等直观比喻，但不强行把所有概念口语化，更不编造对白、强加讥讽或复用同一种比喻。样本中的强烈评价用于已讲清的具体行为，不能把普通工商业、市民或劳动者一并贴成反面人物。

细节、数字和限定词都有任务。房间号、电话数量、报价等只有在解释人物能力、交易链或结果时才保留；“力争”“尽可能”“很可能”等词限制事实边界，不能为让话更有气势而删除。学的是讲清楚、说得实在，不是每段堆数字或刻意模仿本片的用词密度。

写完按实际朗读顺序自查：每次转折是否有前因；抽象词能否落到人、货、钱和动作；短判断前是否已有事实；理论出现时观众是否已看见对应行动；结尾是否回答开头的问题。用户已经定稿时只把这份自查用于提出建议，不据此擅自改稿。

## 制作时的两项修正

合成服务可能返回非空但不完整的音频。不能只检查文件存在或大小；词时序去标点后的文本必须覆盖整段正文。发现截断时仅重试受影响段落（有限次数），替换其相关缓存后重新对齐，仍失败则报告。不要拿旧词时间或 ASR 猜测补齐缺失声音。

复用已认可镜头时区分照片运镜和真正动态影像：静态照片的平稳运镜可以重定时；动态影像优先正常速度裁取，不能为塞进新文案把整段视频默认加速或大幅拉慢。源长度不足时补镜头、换相关素材，文案调整遵守用户授权。照片复用按原底图统计，即使它已经编码成 MP4 也不能绕过计数；选材优先只用一次，必要时再用一次，详见[素材与镜头决策](editorial.md#素材与镜头决策)。
