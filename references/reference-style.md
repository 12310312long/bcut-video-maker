# 提取参考文案与改写表达风格

用户要求学习某条视频的文案或表达方式时使用。先锁定具体链接；只在“这个视频”等指代确实有多个候选时澄清，不重复确认已经给定的参考。

## 先取得实际文本

优先顺序：用户提供的文案或字幕 → 合法可访问的平台字幕 → 原音频自动转写。平台公开字幕不存在或不可访问时直接转写，不把反复抽帧读字幕当常规方案；抽帧只用于核查专名、数字、原声字幕和视觉节奏。无法取得实际内容时说明已读到的范围，不靠标题、简介或记忆声称分析了整条视频。

可使用已有转写 MCP/CLI；本地后备工具见 scripts/reference_text.py。对已取得的本地音频或视频执行：

```text
PYTHON -m pip install -r <skill>/scripts/requirements-asr.txt
PYTHON <skill>/scripts/reference_text.py <参考音频或视频> --output <研究目录/转写> --prompt "已知人物与专名"
```

支持 --start/--duration 抽取局部、--language auto 或语言码、--model、--threads、--cache-dir。默认 small 多语言模型、CPU int8；不依赖 CUDA。首次可能下载模型，缓存留在用户缓存目录，不打包进 skill 或成片交付。语音识别依赖为可选项，不强制所有视频安装。使用 FFmpeg 解码为 PCM，避免依赖 PyAV 的 metadata_errors 接口差异；这是本项目实际遇到并验证的兼容性问题。

输出带时序文本、SRT 和含词时间/置信信息的 JSON。时间均相对所选片段，原文件偏移记录在 source_start_seconds；与原片时间码对应时须相加。不要把这个 JSON 直接当 edge-tts WordBoundary。输入及输出保留在研究目录，避免覆盖用户已认可的字幕。

ASR 可能把银元、人名、书名等识别成同音字。对开头、关键机制、结尾和引文回看原字幕/资料；识别结果是表达分析的输入，不是史实证据。报告实际完成的方式与范围，不能把 ASR 抽核说成人工听音。记录耗时，不承诺每台电脑都能按同样速度转写。

## 提炼可迁移的写法

形成简短“参考表达说明”，记录参考链接与已读范围，提取以下有用维度：

- 开头怎样建立具体困难、利益关系或异常现象，以及多久接回主题。
- 人物何时出现，背景如何穿插，哪些信息用行动和物件交代。
- 句子长短、口语程度、衔接词、解释密度与自然停顿。
- 抽象机制如何拆开：先发生什么，为什么，接下来怎样变化。
- 采访和旁白怎样分工，结尾怎样回扣已经讲过的事实。

只采用适合当前题材的特征，不把博主的口头禅、夸张修辞、专有段落、第一人称经历或未经核查的数字搬进新片。文案写法、配音声线、画面节奏是不同层面；分析文字不能声称已完成声线分析，不因学习文案而自动更换或克隆配音。

## 本项目验证有效的口语叙事

优先让观众知道困难在哪里，再引出解决问题的人。把政策和科学机制写成有因果的行动：采取什么办法、希望解决什么、遇到什么反应、怎样调整、产生什么后果。不要求每段凑齐五步，也不把事情写成必然按计划成功。

先解释一层关键关系，再跟进下一层；用经过核查的人物、物件、地点和交易细节落地。完整事实句和简短判断交替，连接词承担时间和因果，不用连续设问、强行“反转”或反复对账排比代替讲述。适度使用“这里有个关键”等自然提示，不固定成每段开场。

开头可从冲突、人物原声或小事件进入，随后尽快交代理解所需的背景。不能靠虚构心理、现场对白或错用年份的画面增强吸引力。历史人物的坏事必须写清实际行为、规则和后果，不能只报姓名与被捕结果。

课程视频先列必须覆盖的事件、概念与证据，避免参考风格把作业改成别的主题或个人传记。理论联系从已讲过的行动与结果自然引出；必要处可简短出现，系统讨论通常放在后部。引用原文核对篇名、年代和说话人，避免逐项“某某体现某某”。结尾回到前面建立的人或生活变化，不突然新增没展开的例子。

上海 V12 是案例：保留军事解放、入城纪律、银元与米棉较量，用后期专家访谈穿插解释，后部以调查研究和群众实际生活联系课程主题。具体人物、引语、政治主题、时长、两段访谈及五段音乐都不是其他视频的固定模板。

## 制作时的两项修正

合成服务可能返回非空但不完整的音频。不能只检查文件存在或大小；词时序去标点后的文本必须覆盖整段正文。发现截断时仅重试受影响段落（有限次数），替换其相关缓存后重新对齐，仍失败则报告。不要拿旧词时间或 ASR 猜测补齐缺失声音。

复用已认可镜头时区分照片运镜和真正动态影像：静态照片的平稳运镜可以重定时；动态影像优先正常速度裁取，不能为塞进新文案把整段视频默认加速或大幅拉慢。源长度不足时补镜头、换相关素材或调整文案。照片复用按原底图统计，即使它已经编码成 MP4 也不能绕过 2—3 次限制。
