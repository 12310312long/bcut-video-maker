# 上海解放的下一章_V13_旁白

一九四九年四月，解放军突破长江防线，南京解放。战线继续向上海推进。这座城市的工厂、银行、码头和居民区挨得很近。如果强攻市中心，很可能让上海这座全国的经济中心毁于一旦。时任第三野战军司令员兼政治委员的陈毅、副司令员粟裕，依据中央军委和总前委指示，力争在外围歼灭守军主力，尽可能保全市区。五月十二日，上海战役打响。部队从浦东、浦西两翼迂回，钳击吴淞口。进入市区后，又专门交代，限制使用重炮和爆破。二十七日，上海终于全境解放。

解放军进了城，却没有住进民房，都睡在马路上。原来四月一日，第三野战军就颁发了《入城三大公约十项守则》，里面白纸黑字写着，不住民房店铺，不准打扰戏院及一切娱乐场所。一九四九年四月二十五日，毛泽东、朱德颁布的《中国人民解放军布告》，第一条也写明，保护全体人民的生命财产。各界人民，不分阶级、信仰和职业，均望保持秩序，采取和人民解放军合作的态度。



上海是保下来了，可新生政权一接手，经济上的难题就压了过来。国民党统治时期，恶性通货膨胀仍在延续，一大批不法投机商乘机兴风作浪，致使黄金、银元、外币充斥市场，物价猛烈上涨，经济秩序混乱。一些观望的人认为，共产党能够「马上得天下」，但不能「马上治天下」。

普通市民要买米买布，工厂开工需要资金和原料，市面上的银元、外币和紧俏商品，很大一部分攥在投机商手里。更要命的是，上海人已经苦旧纸币久矣。一九四八年八月，蒋介石政府发行金圆券，声称一块顶三百万元法币，并限期兑换，老百姓的黄金、白银和外汇全成了政府的囊中之物。随着旧政府大肆印刷金圆券，物价开始飞速暴涨，到了一九四九年春天，金圆券早已贬得不成样子。所以人民币进城的时候，不少人不信这种新纸币。人民政权能不能制止恶性通货膨胀，把物价稳住，恢复生产，并在政治上站稳脚跟，这是对我党的一次重大考验。

上海滩的投机商，根本没把新政权放在眼里。有人放话，解放军进得了上海，人民币进不了上海。南京路上的四大百货公司公开用银元标价，拒收人民币，人民币早上从人民银行发出去，晚上又回到银行。汉口路的证券大楼，就是这场抵抗的总指挥部。

六楼445房间，是永成证券号经纪人周汉卿的地盘，外号「小广东」。他一个人占了五个连通的房间，摆着一长排对讲电话机，起码能放下五十部。楼里的报价，一通电话就传到街头。他还跟香港、澳门市场保持联络，美元不叫美元，叫「糖」，黄金不叫黄金，叫「人参」，用暗号躲避追查。他手里攥着国民党财政部长俞鸿钧的证明书，身边养着两个律师和一个专职会计。楼里的旧看守都说，小广东最灵光，牌头也最硬。

政府不是没先礼后兵。六月六日，市里集中抛售一万枚银元，想压低价格。可银元刚露面，就被投机商一口吃进，价格反而越抛越高。银元价格十多天里涨了近两倍，大米跟着涨了两倍多，棉纱涨了一倍多。街头上倒卖银元的人，几天里从两万涨到八万。光靠抛售，已经压不住了。这副整顿财经的重任，交到了中共中央政治局委员陈云的手上。陈云，上海青浦人，早年在商务印书馆当过学徒、店员，对上海的钱庄、商号和市面都不陌生。在东北，他主持财经工作，稳物价、筹军粮，什么难缠的账都见过。中央把他调回北平筹组中央财政经济委员会，就是要他来管全国的钱袋子。

中央很快批准了上海的查封方案。两天后的上午，军警突然包围证券大楼，控制通道，停止交易，切断对外的电话线，人员和账册一并清查。当场逮捕了两百多名首要投机分子，抄出的黄金三千多两，银元三万多枚。当天下午，银元价格从一枚两千元跌到一千二百元，百货公司纷纷恢复人民币标价。那些说「人民币进不了上海」的人，被狠狠扇了个耳光。与此同时，税收和水电费，一律改用人民币缴纳，银行也开始收兑金银和外币。抓人封楼只是治标，真正要做的，是让老百姓在日常生活中把新钱用起来。银元风潮很快被压下去，可投机商们很快又把目光转到了粮食、纱布和煤炭上。

米、棉、煤，这座城一天都离不开。上海自己产不了多少，粮食要靠外地运，棉花和煤也要从外面进，海运一封锁，铁路又被战争打断，货就更难进来。有人看准了这个空子，把紧缺物资成批买下，囤在仓库里等涨价。市场上的货越少，老百姓越慌，越慌越抢，价格就这么被一层层推上去。财政赤字和货币发行，更是给物价火上浇油。要稳住市场，一手要把货运进来，一手要管住那些流进囤积买卖的钱。

七月，陈云到了上海。来之前，他心里其实有过一个退一步的打算，疏散一部分工厂、学校和人员。可到了上海，他先跑工厂，再跑市场，把困难一条条摸清楚，原来的设想也跟着改了，重点从疏散转到恢复生产、组织供应。毛泽东在《反对本本主义》里说过，没有调查，没有发言权。先看实情，再改办法，这就是从实际出发。七月二十七日到八月十五日，陈云主持上海财经会议，各大区一起算账，上海缺什么，各地能拿出什么，铁路怎么接，都要一件件落实。

东北的粮食、各地的纱布，通过铁路和各地贸易机构，一车车往上海调。夏天做的这些准备，到秋冬新一轮涨价时派上了用场。十一月十三日，陈云起草部署稳定物价的指示，各地把粮棉集中起来，约好同一天往市场里投，银行和税务部门也一起动手。这场较量，赌的不只是货够不够，还在赌囤货的人还能不能借到钱。

十一月二十五日，全国八个主要城市同时动手，大批物资一起投向市场。上海的纱布市场上，投机商还在抢购，有人甚至借高利贷买货，想着囤几天再高价卖出。可国营公司的货源源不断，牌价一天里改了好几次，棉布价格当天就跌了一半。刚买进的纱布还没转手，市价已经掉下来了，借的钱却还要付利息。银行和税务部门跟着收紧，资金周转越来越难。撑不住的投机商开始卖存货，原先压在仓库里的货，终于重新流回了市场。

货多了，钱紧了，抢购和涨价的风潮慢慢平息下来。可打击投机，打的是囤货居奇、哄抬物价，而不是一棒子打死。工厂要开工，需要有原料；商店要开门，也得有货物进入。货源如何接上，生产怎么恢复，成了上海经济恢复的重要任务。一九五〇年三月，全国财政经济工作进一步统一，稳定物价的底子这才厚了起来。

早在一九四九年三月，七届二中全会在西柏坡召开。毛泽东在会上说，我们能够学会我们原来不懂的东西。我们不但善于破坏一个旧世界，我们还将善于建设一个新世界。几个月后，上海就是这句话要过的第一道关。人民政府没有现成的城市管理经验，只能一趟趟跑工厂、跑市场，先把情况摸清楚，再一条条拿出办法。等到米价稳了，工厂开了工，市民手里的钱又能买到东西，上海用不到一年时间证明，共产党不但能马上得天下，也能马上治天下。
