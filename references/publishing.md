# 封面与投稿材料

用户要求为已有视频准备B站等平台材料时使用。先读取当前成片、最新确认的封面要求、实际版本说明和素材来源，不把旧样板的标题或时长写进新包。制作材料不自动包含上传、投稿、发送动态或联系他人。

## 封面

- 历史题材优先真实人物发言、行动或事件史料，查看原图并核实出处；同一人物的其他场合照片应标为资料，不暗示它是本次讲话现场。不要生成逼真的历史照片替代证据。
- 用户给截图并要求“找到原图直接作封面”时，按人物姿势、手势、周围人物、背景与构图核对同一张照片，取得可用的无文字版本；不要仅找到同一人物的相似照片。直接使用所取原文件，不擅加标题、滤镜、生成式修补或裁切。确需另做平台适配副本时保留原图并说明改动；截图有字不代表用户要求复制截图上的字。
- 更换照片后重查对应来源与使用条件，更新发布文案、来源记录和最终压缩包；不能沿用旧照片的摄影者、档案编号或许可。若同步更新草稿缩略图，登记后也核对实际复制的封面文件。
- 需要设计文字封面时，人名、演讲／事件名构成主要层级，其他日期或版本信息按用户要求取舍。技术特点如“双语”“完整版”不是必须出现的封面卖点。题名与实际音轨版本的边界可在简介解释，不强塞封面。
- 用户明确删除的文字，应从所有比例、导出格式和可编辑源中同步删除。用户只改封面时保留成片；封面独立于开头首帧，除非用户要求同步修改。
- 设计封面时提供可上传的JPG／PNG和可编辑源；用户要求直接用原图时交付原图和出处，无需另造排版源。SVG若把文字转成轮廓，说明可以移动缩放但不能直接改文字，附可重建的文字数据或脚本；若要求直接编辑文字、字号与字体，应交付真实文字对象，并附字体来源与适用许可。不要把位图或字形轮廓称作可直接改字的文本图层。
- 检查实际像素、文件可读性和缩略图效果，确认字不压人物、边缘裁切不丢标题。按投稿页实际裁切准备比例；无法查到官方当前规格时，不把经验尺寸称为强制要求。4:3与16:9可作为备选，非固定全交付规则。

代码原生SVG的排版可用字体字形与真实照片嵌入实现，无需重新生成或修复人物脸部。字体、素材和运行路径尽量随发布包或配置解析，不依赖特定用户名和缓存目录。

## 文案与交付

### 用户确认的同系列文案格式

钢铁雄心4历史演讲系列默认采用用户在2026-10-17确认的格式；以后有新要求时以新要求为准。

- 标题采用 `【钢铁雄心4】主题标题 - 人物年月日的著名演讲`。本次定稿为 `【钢铁雄心4】我们绝不投降 - 丘吉尔1940年6月4日的著名演讲`。不默认在公开标题前后添加“中英双语”“游戏音轨完整版”等技术标签；其他题材按真实内容调整，不生套“著名演讲”。
- 简介先用一段交代历史背景，随后依次使用 `【版本说明】`、`【画面说明】`、`【来源与制作】`，再列原文、录音版本和影像的直接来源链接，最后邀请观众附时间点及原文校订字幕。各部分留空行，便于直接复制投稿。
- 版本说明保持简洁，交代本片题名与原演讲通称，以及原声和音乐的混音关系。没有实际使用“全文／完整版”表述时，不默认扩写成冗长的母带考证或重复技术说明；仍不得把节选或后来录音称为当日现场全文。详细核查记录、许可待确认事项另存交付说明，保留必要事实边界。
- 画面说明交代AI制作、史料混剪、资料照年代、部分画面晚于讲话，以及编辑介绍与原声翻译的区别。本次用户定稿使用“本视频完全由GPT6.1Sol制作”；未来署名应符合实际参与模型和制作过程，不机械沿用同一模型名或虚称所有历史素材为AI生成。
- 来源与制作列出本片编辑工作、演讲人及演讲日期、实际音轨版本与权利人、影像片名及年份、照片摄影者和档案编号。已由用户定稿的文案直接同步到TXT、集中审阅文档和压缩包，避免重新生成时恢复旧标题或加回已删段落。

按本片内容提供一套推荐标题、简介、标签、置顶评论、发布动态和有价值的章节时间码；备选标题少量即可。简介交代背景、版本范围、影像性质及关键来源，避免夸大“现场”“原版”“全文”“独家原创”。章节以实际字幕／时间轴为依据，确认不超片长。

标签与分区应贴合视频实际内容，游戏音轨加历史画面不等于游戏攻略。平台分区、数量限制、封面规格与“自制／转载”等规则会变化，使用时核查当前官方资料或实际投稿页；核实不到就说明是编辑建议，不编造平台要求。

发布包可包含：封面与可编辑源、集中审阅文案、各投稿字段TXT、必要的SRT、素材来源及使用说明。MP4可链接原交付位置，不为凑包重复存储大文件。文案按UTF-8保存；更新后重新导出相关封面、检查并重建ZIP，不能只改源码就交付旧压缩包。成片已烧录双语字幕时，说明SRT用于另加可关闭字幕或后续修订。

## 按具体用途核对许可

搜集素材时区分：历史人物讲话／文献、具体录音版本、游戏或唱片新增配乐、档案影像、照片和字体。公版讲话不自动让后来配乐或录音版本也成为公版；“合法持有游戏”“网上能下载”“许多UP在用”“注明来源”均不能替代实际许可。

用户提出公开发布后，及时核对该素材版本和平台用途的许可，记录官方链接、核查日期、适用范围和未解决项。优先在全片渲染前识别会改变选材的限制；不要为无关视频展开通用法务清单。协议可能变化，不能把某次查到的游戏厂商规则永久写成固定授权。

例如，若厂商限制游戏原声脱离实机画面发布，历史影像混剪就不能仅凭一般游戏直播政策认定获准。存在具体冲突时，完成仍可进行的封面和文案，明确剩余许可问题，不冒称可直接发布；也不为规避规则自动增加几秒游戏画面或擅自替换用户指定音轨。需要时准备询问信草稿，发送仍需用户授权。来源署名与“侵删”等措辞不替代许可。
